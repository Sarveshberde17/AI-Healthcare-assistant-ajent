# AI Research Agent 🤖

## 📌 Project Overview
AI Research Agent is a Python-based application that helps users research any topic automatically using web search technology.

It collects information from different websites and displays relevant research results with source links.

## 🎯 Objectives
- Automate the research process.
- Collect information from multiple websites.
- Save time and effort.
- Display relevant research results.
- Help users understand different topics.

## 🛠️ Technologies Used
- Python
- Streamlit
- Tavily Search API
- AI / Machine Learning (Future Enhancement)

## ⚙️ Features
- Simple and user-friendly interface.
- Search any research topic.
- Collect information from the internet.
- Display website titles and descriptions.
- Provide source URLs.
- Fast research results.

## 📥 Installation

### Step 1: Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the project folder

```bash
cd AI-Research-Agent
```

### Step 3: Install required libraries

```bash
pip install -r requirements.txt
```

### Step 4: Run the application

```bash
streamlit run app.py
```

## 🔑 API Configuration

1. Create an account on Tavily.
2. Generate your API key.
3. Enter your API key in the application.
4. Enter your research topic.
5. Click Start Research.

## 🚀 How It Works

1. User enters a research topic.
2. The system sends a search request.
3. Tavily collects relevant web results.
4. The application displays collected information.
5. Users can open the original source links.
